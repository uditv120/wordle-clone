# Lexicon Supreme - Ultimate Deluxe Wordle

An advanced Wordle game featuring multiple game modes, visual themes, challenge links, speech synthesis, and progression systems.

## 🌟 Deluxe Features
- **🎨 5 Visual Themes**:
  - *Midnight Slate* (Default sleek dark aesthetic)
  - *Cyberpunk Neon* (Vibrant purple/magenta/cyan neon glow)
  - *Retro Matrix* (Dark phosphor terminal green)
  - *Sunset Amber* (Warm bronze, gold, and deep copper)
  - *Paper Clean* (High-contrast clean daylight theme)
- **🎯 Challenge a Friend**:
  - Create encrypted custom challenge links with your own 4, 5, or 6-letter secret words.
  - Send the URL to friends and see how many tries it takes them to solve!
- **🔊 Speech Pronunciation & Live Dictionary**:
  - Click the 🔊 speaker button on the victory card to listen to correct English pronunciation via Web Speech API.
  - Live definition lookup via free Dictionary API showing phonetics, part of speech, and comprehensive definitions.
- **🏆 Career Achievements & Badges**:
  - 11 unlockable badges (First Blood, Speed Demon, Mind Reader, Hot Streak, Unstoppable, Duo Master, Ironclad, Gold Hoarder, Grandmaster, Purist, Challenger).
  - Track earned achievements directly from the career stats modal.
- **🎮 Multiple Game Modes**:
  - **Endless**: Continuous non-repeating streak-building rounds.
  - **Daily**: Global synchronized puzzle for every calendar day.
  - **Speed Rush**: 60-second rapid blitz with +15s bonus per solved word.
  - **Duo Lexicon**: Solve 2 hidden words simultaneously across dual boards!
- **🪙 Power-Ups & Lifelines**:
  - Spend earned streak coins on *Scout* (reveal green), *Cull* (eliminate 3 wrong letters), *Hint* (clue), or *+Row* (extra attempt).
- **📳 Haptics & Web Audio**:
  - Vibration API tactile response for mobile keystrokes and victory fanfare.
  - Polyphonic synthesizer for game audio with no external sound asset dependencies.
