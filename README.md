# Lexicon Supreme - Wordle Clone

An advanced Wordle clone featuring multiple game modes:
- **Classic**: Traditional 6-guess Wordle mechanics with animations and hints.
- **Endless**: Streak-building continuous mode with expanding dictionaries.
- **Speed Rush**: Beat the clock with rapid-fire word solving.
- **Duos**: Dual-board simultaneous guessing challenge.

## Tech Stack
- Single-page application (HTML5, Tailwind CSS, Vanilla JavaScript)
- Completely client-side, zero backend dependencies.
